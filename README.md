# Packhelfer

Smarte Packliste für Reisen – als PWA auf dem Handy nutzbar.

## Auf GitHub Pages deployen

```bash
cd "/Users/thomasbuchal/Desktop/Werkbank/Aktiv/Claude Playground/Packliste/packhelfer"
git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/DEIN-USERNAME/packhelfer.git
git push -u origin main
```

Dann auf GitHub: **Settings → Pages → Source: main / (root)** → Save.

URL: `https://DEIN-USERNAME.github.io/packhelfer/`

## Auf dem iPhone hinzufügen

Safari → Teilen → **„Zum Home-Bildschirm"**
